# TensorFlow Lite inference. `ai-edge-litert` is the lightweight interpreter
# (no full TensorFlow needed) for actually running a .tflite model; getting
# a .tflite in the first place needs `litert-torch` (formerly `ai-edge-torch`)
# to convert from PyTorch, which pulls in full `tensorflow` -- and neither
# has a wheel for every Python version yet (check before assuming this
# installs cleanly on a brand-new Python release).
ai-edge-litert
litert-torch

# TensorRT inference (Jetson only -- needs an NVIDIA GPU). NOT a plain pip
# install on most machines: on Jetson, `tensorrt` ships as a system package
# via JetPack, so build your venv with `--system-site-packages` instead of
# `pip install tensorrt`. `pycuda` is a normal pip install once CUDA is
# present. Leave these commented out unless you're actually on Jetson.
# pycuda

# ExecuTorch inference. Pure pip install where it has a wheel at all, but
# (as of this writing) it doesn't ship one for every recent Python version
# -- check `pip index versions executorch` before assuming it installs
# cleanly on a brand-new Python release, same caveat as ai-edge-litert/
# litert-torch above.
executorch

# TVM inference. `apache-tvm` has no prebuilt wheel for every platform --
# where none exists, pip tries to build its `apache-tvm-ffi` component
# from source via CMake, which needs a working C/C++ compiler toolchain
# installed and on PATH. Check `pip install apache-tvm` succeeds before
# assuming this works; if it tries to compile from source, either install
# a compiler toolchain or skip this one.
apache-tvm

# CoreML inference. Plain pip install anywhere, no compiler needed --
# conversion (coremltools.convert) works on any platform. Actually
# *running* the converted model (MLModel.predict()) only works on
# macOS/iOS -- confirmed on this project's own Windows dev machine, it
# raises a clean "Model prediction is only supported on macOS" error, the
# same shape as TensorRT needing an NVIDIA GPU.
coremltools

# MNN inference (Alibaba). Normal pip install, but its bundled
# mnnconvert.exe has confirmed, undisclosed pip-install-on-`--help`

# of printing usage, it silently started `pip install
# aliyun-log-python-sdk` and a chain of unrelated network dependencies --
# no --help output at all). Nothing from that completed here, and mnn has
# been uninstalled from this project's environment as a precaution. See
# frameworks/mnn_adapter.py's docstring before installing this or running
# its conversion step -- deliberately left unexercised.
# mnn

# SNPE inference (Qualcomm). Not a pip package -- requires manually

# rknn-toolkit2
